# Compliance status (2026-11-10, 0.15.1)

This file tracks third-party license obligations for the repository. Detailed
component data is in `licenses/README.md`; upstream provenance and modification
records are in `editor/PROVENANCE.md` and `editor/MODIFICATIONS.md`.

> This is an engineering compliance record, not legal advice. Have counsel
> review the remaining medium-risk items before commercial distribution.

## Resolved in 0.15.1 — libavoid (LGPL-2.1) removed

draw.io 31.4.5 appended libavoid (LGPL-2.1) to `editor/js/extensions.min.js`.
Because the draw.io libavoid build sources were not publicly available, the
LGPL source/replaceability obligation could not be satisfied. In 0.15.1 the
append is removed:

- [x] `editor/js/extensions.min.js` is generated by
      `scripts/build-drawio-extensions.mjs` from the upstream draw.io 31.4.5
      bundle; the 627,678-byte libavoid tail (`libavoid.min.js`,
      `libavoid-routing.js`, `LibavoidRouting.js`) is not distributed.
- [x] `editor/js/libavoid-js/` and `licenses/lgpl-2.1.txt` were deleted.
- [x] `test/editor-license.mjs` guards the bundle and the absence of the
      libavoid directory/license text.
- [x] No LGPL component remains in the package. The only functional loss is the
      draw.io **Arrange → Layout → Orthogonal Routing** auto-routing action;
      ordinary orthogonal edge styles are draw.io core and unaffected.

## Distribution policy

- **GitHub public source**: allowed. The repository is a truthful record of the
  upstream components and the libavoid removal.
- **npm publish / GitHub Release**: the libavoid LGPL blocker is resolved; no
  LGPL component is distributed. The remaining medium items (ELK EPL source
  pointer, PlantUML converter provenance) should be reviewed/counsel-cleared
  before commercial distribution; they do not block publishing the package as
  documented open source.
- If the embedded draw.io editor is removed from the distribution, items 1–4
  mostly disappear and the repository becomes a plain MIT plugin.
